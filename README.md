The Mushroom Classification System is a machine learning project designed to predict whether a mushroom is edible or poisonous based on its physical characteristics. It uses a labeled dataset of various mushroom attributes such as cap shape, color, odor, gill size, and habitat to train a classifier that helps in identifying the nature of unknown mushroom species.

✅ Key Features
Classification of mushrooms as edible or poisonous

Uses supervised learning algorithms (e.g., Decision Tree, Random Forest, or SVM)

Handles categorical data preprocessing

Provides model accuracy, confusion matrix, and classification report

Simple and user-friendly implementation

📁 Dataset
The system uses the publicly available UCI Mushroom Dataset, which contains 8124 instances of mushroom samples with 22 categorical attributes.

💡 Use Cases
Assisting mushroom foragers or researchers in identifying poisonous species

Demonstrating practical use of classification models in real-world datasets

Educational tool for machine learning learners
